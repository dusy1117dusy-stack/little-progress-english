# 一点进步 · 手机本地版

每天 40 分钟英语。四级优先，默认过滤常见基础词，保留重要多义词。四级阶段首轮后依次进入六级、雅思。词库来自 ECDICT（MIT），不是官方完整考纲。

无需账号或服务器数据库。打卡、笔记、词汇进度保存在当前浏览器的 localStorage。学习计划页可以导出 JSON 备份及导入恢复，也兼容旧同步版导出的备份。

请固定使用手机同一个浏览器，不使用无痕模式；清除网站数据、更换网址或浏览器会失去对原记录的访问。每周导出到手机文件。网页成功加载并完成离线缓存后，可在离线时再次打开；浏览器可能清理缓存，离线缓存不替代记录备份。

## GitHub Pages 发布

创建专用仓库，将本文件夹的文件放在仓库根目录。在 Settings → Pages 选择 Deploy from a branch，分支 main、目录 / (root)，保存。发布完成后使用 GitHub 返回的网址访问，不要猜测网址。无需构建、Actions 工作流或服务器密钥。学习记录不在仓库里。

首次在手机普通网络打开发布网址，测试打卡、关闭重开、词卡和导出备份。GitHub Pages 在你所在网络的连通性必须实测。
